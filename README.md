# Broadcast ShoppingMall

방송 기반 쇼핑몰 백엔드 시스템입니다.

## 주요 기능
- 상품 관리, 주문/결제/배송 프로세스
- 실시간 방송 연동(상품 노출, 판매 이벤트)
- 관리자/사용자 역할 분리 및 권한 관리
- 통계 및 리포트 기능

## 기술 스택
- Java, Spring Boot, JPA, MySQL
- REST API

## 프로젝트 구조
- 방송/상품/주문/사용자 도메인별 모듈화
- 이벤트 기반 상품 노출/주문 처리
- 주문/결제 트랜잭션 안정성

## 실행 방법
```bash
./gradlew bootRun
```
